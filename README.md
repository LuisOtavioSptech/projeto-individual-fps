# 🎯 Jogos de FPS na Minha Vida

Um projeto sobre como os jogos de FPS fizeram e ainda fazem parte da minha vida.

O site conta essa história e tem uma dashboard onde cada usuário cadastra suas partidas de Valorant e acompanha seu desempenho por mapa, por agente e em vitórias x derrotas.

**Tecnologias:** HTML, CSS, JavaScript, Node.js e MySQL
